# tree-d
A 3d renderer i wrote in javascript for ABSOLUTELY no reason.

## So basically
It started out as a CodeHS sandbox project where I figured how to track vertex and edges as tables and render them using Lines. Then, i learned how to use trig to rotate them.

Now, i migrated everything to matrix math, with my locally made linear algebra library to help. It's my first experience with 3d rendering, and I'm loving it.
